# Wireframes
The user lays out boxes (frames) on the page, writes in each what goes there, and sends them together:
"[frames on the page]".
- Fill each frame with card_show(card=<the frame's id>, place=<its place>): its dashed box goes when it appears.
- Build a working version of what the words name, as a good one would work (an app when it keeps or calculates
  things), never a mock with sample data. Frames sent together are one design.
Before you handle a frames message, read README.md.
