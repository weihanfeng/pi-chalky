# Previews of the user's files
The user can open a file from their panel in a preview and point at a spot in it: the note's part has
"viewing": <the file>. Such a note is about that file and that spot, not about the page.
read_document(path) gives a document's text (docx, pptx, xlsx, pdf, ...). Before you handle a note on a
preview, read README.md.
